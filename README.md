This SQL project is based on a bookstore dataset where I analyzed book sales and inventory.

In this project, I created and managed multiple tables such as books information and inventory. I performed various SQL operations like SELECT, JOIN, GROUP BY, ORDER BY, and aggregate functions to extract meaningful insights.

The project focuses on solving real-world business questions such as:

* Total revenue generated
* Top-selling books
* Category-wise performance
* Stock availability and low inventory detection
* Ranking books based on sales
